| **1.2.0** | **New:** Pings from other players show names in your own language and outline exactly the object they pinged. Removing a collection section can be undone. Settings are neatly ordered in Configuration Manager, with rarely needed ones under Advanced. The Z key setting is renamed from Mob Highlight Shortcut to Ping Shortcut; a custom key is kept. Friendly creatures are now outlined in blue instead of green, which is easier to tell apart from hostile red for colorblind players.<br>**Servers:** Only admins can change prefab collections, even when Lock Configuration is off. Collections are now kept in their own file, `JoksterCube.PingMark.Collections.yml` (moved automatically), and changes to it reach players right away. Ping spam from a single player is limited. Ping Cooldown now also applies to creature and player highlights.<br>**Fixes:** A typo in the collections settings no longer resets all collections. Fixed creature nameplates occasionally looking wrong. Fixed an old version error appearing on unrelated connection problems. Fixed names losing their numbers. Shortcuts no longer trigger while extra keys are held (Ctrl+Z no longer pings). If a game update breaks part of PingMark, the rest keeps working instead of causing errors.<br>**Performance:** Smoother outlines and menus, and less work every frame.<br>**Important:** Everyone on a server with PingMark must update to 1.2.0. Future updates will only require this when noted. |
