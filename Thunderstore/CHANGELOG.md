| Version | Update Notes |
|----------|---------------|
| **1.3.0** | **New:** Perception (Left Shift + Z) briefly outlines listed objects and dropped items around you, so coins and gems are easy to find in dark dungeons. Nearby PingMark players see the outlines too, and Perception Fatigue limits how often it can be used. Turn on Perceive Creatures and Perception also highlights every hostile and friendly creature around you, beyond the usual highlight limit. Flying birds can now be pinged. The Prefab Collections menu can copy and import all sections as YAML, import a single section from a copied list, and export a report of how every prefab was sorted (handy for modded prefabs).<br>**Auto Sort:** Smarter with modded prefabs. Rocks and debris that only drop wood, stone, grausten or ice, plain bushes, spreading fires and developer test locations are no longer listed. New menu filters for dungeon rooms and common-drop objects. Press Auto Sort in the menu to rebuild your sections with the new rules.<br>**Changes:** Friendly creatures are outlined in green again, matching their health bar. Configs still on the old default switch automatically; a color you picked is kept.<br>**Fixes:** Dungeon walls and floors are no longer outlined or named when pinged; chests, pickables, doors and other objects inside dungeons still are. Pinging the walls of a troll cave, ruin or other location names it without outlining a random part of the whole site.<br>**Important:** On a server with PingMark, everyone with the mod must use the same version as the server, so update together to 1.3.0. Players without the mod can still join. |
| **1.2.0** | **New:** Pings from other players show names in your own language and outline exactly the object they pinged. Removing a collection section can be undone. Settings are neatly ordered in Configuration Manager, with rarely needed ones under Advanced. The Z key setting is renamed from Mob Highlight Shortcut to Ping Shortcut; a custom key is kept. Friendly creatures are now outlined in blue instead of green, which is easier to tell apart from hostile red for colorblind players.<br>**Servers:** Only admins can change prefab collections, even when Lock Configuration is off. Collections are now kept in their own file, `JoksterCube.PingMark.Collections.yml` (moved automatically), and changes to it reach players right away. Ping spam from a single player is limited. Ping Cooldown now also applies to creature and player highlights.<br>**Fixes:** A typo in the collections settings no longer resets all collections. Fixed creature nameplates occasionally looking wrong. Fixed an old version error appearing on unrelated connection problems. Fixed names losing their numbers. Shortcuts no longer trigger while extra keys are held (Ctrl+Z no longer pings). If a game update breaks part of PingMark, the rest keeps working instead of causing errors.<br>**Performance:** Smoother outlines and menus, and less work every frame.<br>**Important:** Everyone on a server with PingMark must update to 1.2.0. Future updates will only require this when noted. |
