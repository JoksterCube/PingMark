| **1.2.0** | **New:** Prefab collections now live in `JoksterCube.PingMark.Collections.yml` and are migrated automatically. On a PingMark server only admins can change them (checked by the server), and edits to the server's file reach players live. Pings from other players show target names in your language and outline exactly the object they pinged. Removing a collection section can be undone. Settings are ordered in Configuration Manager, with technical ones under Advanced. The ally outline is now blue by default so it stays distinct from hostile red for colorblind players; an untouched old green default is updated.<br>**Fixes:** An invalid collections value no longer resets all collections. Creature nameplates no longer use a stale label style or shift alert markers twice. An old version-mismatch message no longer appears on unrelated connection errors. The Unassigned color is saved for remote admins. Translated names keep their digits. Shortcuts match modifiers exactly (Ctrl+Z no longer triggers Z). Highlights and pending pings are cleared when leaving a world. If a game update breaks a feature, that feature is switched off with one log message instead of erroring every frame.<br>**Server:** Malformed or oversized ping packets are dropped and each player is rate limited. Ping names are capped at 64 characters. Ping Cooldown also applies to highlights. Without a modded server, your own broadcast distance also applies.<br>**Performance:** Outlines use fewer draw calls, cap very large targets and check object changes less often. No per-frame allocations for shortcuts or map labels, the menu's UI only runs while it is open, and searching the menu is faster.<br>**Compatibility:** Servers now compare a network protocol number instead of the exact mod version, so only updates that change the network format require everyone to update. This release does: everyone on a PingMark server needs 1.2.0 or later. |
